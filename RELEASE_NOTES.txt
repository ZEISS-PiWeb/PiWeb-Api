==========================================
 Bugfixes
==========================================
- Correct request URI and endpoint path handling, including slashes and trailing endpoint name in HealthServiceRestClient (#305)


==========================================
New Features
==========================================
- Support externally managed HttpClient instances and custom request handler chains (#305)
    ○ Refactor REST-client abstractions, service interfaces, and configuration handling
    ○ RestClient class represents the default implementation for desktop scenarios, using an internal HttpClient as before
    ○ HttpClientRestClient class allows providing an externally managed and configured HttpClient, e.g. for browser scenarios
    ○ For the simple usage of the Data/RawDataServiceRestClients, no breaking changes should surface for desktop clients
    ○ For scenarios with custom rest clients implementing our interfaces, changes may be necessary
- Remove browser/WASM platform support from RestClient class (#307)
    ○ Direct consequence of #305
    ○ In browser scenarios, use HttpClientRestClient and inject an HttpClient instance directly to the service REST clients
- Add a standalone caching extension with ICachingHandlerFactory and CacheCow-based filesystem stores (#308)
    ○ Introduce ICachingHandlerFactory to abstract caching handler creation and move CacheCow-based caching to new Api.Rest.Caching project
    ○ Update RestClient and builder to use the new factory, removing direct CacheCow dependencies
    ○ Reduces overhead in browser scenarios, since caching is handled by the browser itself
- Add several new keys to WellKnownKeys (#303 and #309)
    ○ Add well-known keys for part distribution analysis mode
    ○ Add well-known keys for measurement callback URI and callback description
